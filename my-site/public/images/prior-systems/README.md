## How to Add Images

1. Take screenshots from your deployed app at https://priorsystems.net
2. Use a screenshot tool like:
   - **Windows:** Snipping Tool, Greenshot
   - **Mac:** Shift + Cmd + 4
   - **Cross-platform:** Kap (for GIFs), ShareX

3. Edit images to proper dimensions using:
   - **Online:** Photopea, Canva
   - **Desktop:** GIMP, Photoshop, Preview (Mac)

4. Save files with the exact names listed above
5. Place them in this folder

## Image Optimization

Before adding images, optimize them:
- Use TinyPNG or ImageOptim to reduce file size
- Keep GIFs under 5MB for fast loading
- Use PNG for screenshots with text
- Consider WebP format for better compression
